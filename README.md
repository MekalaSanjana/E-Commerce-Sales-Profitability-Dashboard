# 🛒 E-Commerce Sales, Customer & Profitability Dashboard

## 📌 Project Overview

This project analyzes e-commerce sales data to understand **sales performance, customer behavior, product profitability, and regional trends**.

The project combines **Python, SQL, Excel, and Power BI** to transform raw sales data into meaningful business insights and an interactive dashboard.

### 🎯 Business Questions

* How are sales and profit changing over time?
* Which products generate the highest revenue?
* Which products are loss-making?
* Who are the top customers?
* Which regions and categories perform best?
* Which customer segments contribute the most revenue?
* What factors are affecting profitability?

---

## 🛠️ Tools & Technologies

* **Python** — Data cleaning and exploratory analysis
* **Pandas & NumPy** — Data manipulation
* **Matplotlib & Seaborn** — Data visualization
* **SQL / MySQL** — Business analysis and queries
* **Microsoft Excel** — Data preparation and supporting analysis
* **Power BI** — Interactive dashboard and data visualization

---

## 📊 Key KPIs

| KPI              | Description                              |
| ---------------- | ---------------------------------------- |
| 💰 Revenue       | Total sales generated                    |
| 📈 Profit        | Total profit generated                   |
| 🛒 Orders        | Total number of orders                   |
| 👥 Customers     | Number of unique customers               |
| 🧾 AOV           | Average Order Value                      |
| 📊 Profit Margin | Percentage of revenue retained as profit |
